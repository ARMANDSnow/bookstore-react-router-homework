# 3A：政策加载、分块与真实向量检索

正式政策是 `backend/src/main/resources/store-policy.txt`，明确标注课程演示，不执行退款或会员交易。按二级标题分成6段完整条款；保留拆封限制与质量问题例外，不按固定字数切断句子。过长或无标题文档会报错，修改文本后需重启伴随服务。

使用官方 Transformers.js 3.8.1，`Xenova/bge-small-zh-v1.5`，固定revision `75c43b069aac4d136ba6bc1122f995fedcfd2781`，CPU、q8、CLS pooling、单位化，产生512维有限实数向量。查询使用模型建议的中文检索前缀，政策正文不加前缀。量化权重24010842字节，SHA256 `15b717c382bcb518ba457b93ea6850ede7f4f1cd8937454aa06972366cd19bcc`，与官方LFS对象哈希一致。

算法用归一化向量的点积即余弦相似度排序，返回最多3段、相似度至少0.62的政策原文。实际中文改写样例中，拆封退货约0.70、缺页约0.67、积分约0.67，月球天气无片段过阈值。该阈值只在本课程的小型政策集上校准，相似度不等于准确率，也不能证明所有开放问题均会正确拒答；最终导购需结合原文条件，不把检索当作退款审批。

向量缓存身份含政策SHA256、模型revision、分块版本、pooling与dtype；内容变化生成新缓存。启动有loading/ready/failed状态。Node只监听127.0.0.1:8091，Java访问伴随服务，浏览器访问Spring接口；不可用时返回HTTP503，不返回伪向量或伪造“政策未覆盖”。

启动：`cd embedding-service && npm ci && npm run download-model && npm start`，之后启动后端与前端，访问 `/policies`。下载脚本通过curl读取官方固定版本，检查权重哈希；模型与向量缓存放在忽略的 `.cache`，运行时不再联网取模型。初次Node下载曾出现ECONNRESET，改为此显式可复核的缓存下载流程。

验收：`mvn clean test` 66项通过；`npm run build` 通过；`node scripts/assignments/verify_policy.mjs` 验证原文未丢失、512维单位向量、6类真实中文检索与非法输入；`verify_policy_cache.mjs` 验证离线缓存复用与临时政策变化后重建。桌面验收查询、无依据、全文、网络断开和重试；另实际停掉向量进程，确认后端503及页面恢复。证据见 `3a-*.json`，本轮不测试手机比例。

官方依据：[中文模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)、[ONNX模型仓库](https://huggingface.co/Xenova/bge-small-zh-v1.5)、[Transformers.js文档](https://huggingface.co/docs/transformers.js/v3.8.1/en/pipelines)。本项目使用真实模型文件与实际推理结果，未用随机向量、关键词判断或模拟Embedding替代。
