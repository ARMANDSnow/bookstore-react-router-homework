# 作业4 Java 21 虚拟线程与 JWT 无状态认证

应用系统体系架构 · 学号 524031910745 · 姓名 丁宇轩

本次实现使用 Spring Boot 3.3.5、Java 21 和 JJWT 0.13.0。用户通过密码校验后获取签名 JWT，访问受保护的图书 REST 资源时由 Filter 逐请求验签。Web 请求直接由虚拟线程执行，慢查询使用可配置的 `Thread.sleep` 模拟。

## 评分项与实现位置

| 要求 | 实现 |
| --- | --- |
| RESTful 图书查询 | `GET /api/secure/books/{id}`，返回 JSON；不存在返回 404 |
| Java 21 虚拟线程 | `backend/pom.xml` 设置 Java 21；`application.yml` 开启 `spring.threads.virtual.enabled: true` |
| JWT 库与生成 | JJWT api/impl/jackson；`TokenController` 校验密码，`JwtTokenService` 签发 HS256 token |
| 无状态过滤器 | `JwtAuthenticationFilter` 校验 Authorization；STATELESS、NullSecurityContextRepository、禁用请求缓存 |
| 401 与 200 截图 | `docs/assignments/evidence/assignment4/401.png`、`200.png`；另有登录截图 |

JWT 是带数字签名的身份凭证。服务端验证签名、签发者、身份和过期时间，无需保存登录 Session。虚拟线程是 Java 21 提供的轻量线程，适合大量等待数据库、网络等 I/O 的请求；它不使 CPU 密集计算自动变快。

## 运行

需要 JDK 21、Maven 3.8+、Python 3。首次构建由 Maven 下载依赖，需要网络；提交包不含任何第三方 JAR。请先将 `JAVA_HOME` 指向 JDK 21，确认 `java -version` 与 `mvn -version` 均使用 21。

在解压后的根目录运行：

```bash
bash scripts/assignments/run_assignment4.sh
```

访问 `http://127.0.0.1:8084/assignment4.html`。依次点击“登录获取 JWT”“不携带 Token 查询”“携带 Token 查询”，可查看真实 HTTP 响应。演示账号为 `demo / 123456`，图书 ID 为 `assignment4-book`。JWT 只保存在该页面内存中，截图隐藏完整凭证。

启动脚本使用隔离 H2 内存数据库，启动时自动建表并写入示例图书、BCrypt 密码用户；停止后数据销毁。不会访问或修改本机 MySQL。默认模拟查询等待 200ms，可使用 `PORT=8085 CATALOG_DELAY_MS=500 bash scripts/assignments/run_assignment4.sh` 调整。延迟最大 5000ms。

未配置 `JWT_SECRET` 时，每次启动生成随机签名密钥，重启会使旧 token 失效。需要稳定或多实例运行时，启动前设置相同的 `JWT_SECRET`，它须为至少 32 字节随机数的 Base64 编码，例如：

```bash
export JWT_SECRET="$(openssl rand -base64 32)"
```

不要把真实密钥写入源码、截图或提交包。默认 token 有效期 3600 秒，可用 `JWT_TTL_SECONDS` 配置为 1 到 86400 秒。

## 手动接口验证

无 token 返回 401：

```bash
curl -i http://127.0.0.1:8084/api/secure/books/assignment4-book
```

登录签发 token：

```bash
curl -s http://127.0.0.1:8084/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"demo","password":"123456"}'
```

将返回的 `data.accessToken` 复制为下面的 TOKEN：

```bash
curl -i http://127.0.0.1:8084/api/secure/books/assignment4-book \
  -H 'Authorization: Bearer TOKEN'
```

成功返回 200，响应头包含 `X-Thread-Virtual: true`、`X-Thread-Name: tomcat-handler-...` 和 `X-Java-Version: 21...`。这些信息在实际查询线程中读取。错误、篡改、过期、签名错误或缺失 token 均返回 401，并带 `WWW-Authenticate: Bearer`。有效 token 查询不存在的图书返回 404。
